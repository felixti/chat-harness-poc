# Technical research

1. `tool_search` for "documentation library" to load the Context7 tools (`resolve-library-id`,
   `query-docs`). They are not loaded until you search.
2. Resolve the library id first, then query the docs with a specific question (one concept per query).
3. At most 3 documentation calls per question.
4. Answer with the code or configuration the docs show, and list the sources (library id and
   topic) at the end.
5. If the docs do not cover it, say so; do not fill gaps from memory without saying they are unverified.
