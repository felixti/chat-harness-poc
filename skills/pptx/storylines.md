# Storylines

Pick the closest structure before writing titles, then adapt it. Every deck starts with `title`
and ends with `closing`; the structures list the slides in between. Slide counts include both.
Structures adapted from nextlevelbuilder/ui-ux-pro-max-skill `slide-strategies.csv` (MIT).

| Deck | Slides | Structure | Arc |
|---|---|---|---|
| Executive recommendation (default) | 8-12 | Stakes (big_number) -> Situation (kpis) -> 2-3 insights (chart) -> Options (comparison) -> Recommendation (statement) -> Plan (timeline) | Situation -> Insight -> Decision |
| Quarterly / results review | 10-15 | Executive summary (bullets) -> Goals vs results (table or chart) -> Numbers (kpis) -> Wins (cards) -> Challenges (two_column) -> Next quarter (timeline) | Review -> Analyze -> Plan |
| Research / topic briefing | 8-12 | Why it matters (big_number) -> Context (cards) -> 3 findings (chart or kpis, each with a takeaway) -> Expert voice (quote, real and sourced) -> Implications (bullets) | Hook -> Teach -> Implications |
| Sales pitch | 7-10 | Their problem (statement) -> Cost of inaction (big_number) -> Solution (cards) -> Proof (kpis, quote) -> Differentiators (comparison) -> Return (chart) | Pain -> Solve -> Prove |
| Product / project proposal | 6-10 | Problem (statement) -> Solution (cards) -> How it works (timeline) -> Benefits (kpis) -> Options (comparison) -> Plan and cost (table) | Problem -> Solution -> Ask |
| Competitive analysis | 6-10 | Landscape (cards) -> Comparison matrix (table) -> Pricing (chart) -> Strengths and weaknesses (two_column) -> Our position (statement) -> Strategy (timeline) | Landscape -> Strategy |
| Training / workshop | 12-25 | Objectives (cards) -> Agenda -> per concept: section, bullets, example (image, chart or two_column) -> Summary (cards) | Learn -> Practice -> Apply |
| Board meeting | 15-20 | Agenda -> Executive summary (bullets) -> Financials (kpis, chart) -> Operations (chart or table) -> Risks (two_column) -> Decisions needed (statement) | Report -> Discuss -> Decide |

Contrast keeps attention (Nancy Duarte's "what is / what could be"): alternate the current
state (data, problem) with the better state (opportunity, plan), and end on the new state.
