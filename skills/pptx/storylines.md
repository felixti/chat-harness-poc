# Storylines

Pick the closest structure before writing titles, then adapt it. Slide counts are guides.
Structures adapted from nextlevelbuilder/ui-ux-pro-max-skill `slide-strategies.csv` (MIT).

| Deck | Slides | Structure | Arc |
|---|---|---|---|
| Executive recommendation (default) | 8-12 | Title -> Big number (the stakes) -> KPIs (situation) -> 2-3 charts (insight) -> Comparison (options) -> Statement (recommendation) -> Timeline (plan) -> Closing (asks) | Situation -> Insight -> Decision |
| Quarterly / results review | 10-15 | Title -> Executive summary (bullets) -> Goals vs results (table/chart) -> KPIs -> Wins (cards) -> Challenges (two_column) -> Next quarter (timeline) -> Closing | Review -> Analyze -> Plan |
| Research / topic briefing | 8-12 | Title -> Big number (why it matters) -> Context (cards) -> 3 findings, each chart or kpis + takeaway -> Quote (expert voice) -> Implications (bullets) -> Closing (sources, next steps) | Hook -> Teach -> Implications |
| Sales pitch | 7-10 | Hook (their problem) -> Cost of inaction (big_number) -> Solution (cards) -> Proof (kpis, quote) -> Differentiators (comparison) -> ROI (chart) -> Closing (next step) | Pain -> Solve -> Prove |
| Product / project proposal | 6-10 | Problem (statement) -> Solution (cards) -> How it works (timeline) -> Benefits (kpis) -> Options (comparison) -> Plan and cost (table) -> Ask | Problem -> Solution -> Ask |
| Competitive analysis | 6-10 | Landscape (cards) -> Comparison matrix (table) -> Pricing (chart) -> Strengths/weaknesses (two_column) -> Our position (statement) -> Strategy (timeline) | Landscape -> Strategy |
| Training / workshop | 12-25 | Objectives (cards) -> Agenda -> per concept: section + bullets + example -> Summary (cards) -> Resources (closing) | Learn -> Practice -> Apply |
| Board meeting | 15-20 | Agenda -> Executive summary -> Financials (kpis + charts) -> Operations -> Risks (two_column) -> Decisions needed (statement) | Report -> Discuss -> Decide |

Contrast keeps attention (Nancy Duarte's "what is / what could be"): alternate the current
state (data, problem) with the better state (opportunity, plan), and end on the new state.
